# AI Study Assistant

基于 Android/Kotlin 和 FastAPI 的移动端 AI 学习助手。

## 项目简介

用户可以上传学习资料，系统通过 RAG 构建个人知识库，并支持基于资料的 AI 问答、流式输出、历史记录和来源引用。

## 技术栈

### Android

- Kotlin
- Jetpack Compose
- MVVM
- Room
- Retrofit / OkHttp
- Coroutine

### Backend

- FastAPI
- Python
- RAG
- Vector Database
- LLM API
